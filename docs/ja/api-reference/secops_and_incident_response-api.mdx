脅威レベル分類による悪意あるユーザーの軽減。不審な行動パターンに対する自動応答アクション。

- **カテゴリ**: セキュリティ
- **複雑度**: シンプル
- **パス数**: 4 | **スキーマ数**: 32
- **ティア**: アドバンスド
- **関連ドメイン**: `bot_defense`, `virtual`, `network_security`

## ユースケース

- 自動脅威軽減ポリシーの設定
- 悪意あるユーザー検出ルールの定義
- インシデント対応ワークフローの管理
- 脅威へのブロッキングまたはレート制限の適用

## 主要リソース

- **mitigation_policy**: インシデント対応のための軽減ポリシー
- **malicious_user_rule**: 脅威軽減のための悪意あるユーザールール

## エンドポイント

| メソッド | パス | 説明 |
|--------|------|-------------|
| POST | `/api/config/namespaces/&#123;metadata.namespace&#125;/malicious_user_mitigations` | 悪意あるユーザー軽減の作成。 |
| PUT | `/api/config/namespaces/&#123;metadata.namespace&#125;/malicious_user_mitigations/&#123;metadata.name&#125;` | 悪意あるユーザー軽減の置換。 |
| GET | `/api/config/namespaces/&#123;namespace&#125;/malicious_user_mitigations` | 悪意あるユーザー軽減の一覧表示。 |
| GET | `/api/config/namespaces/&#123;namespace&#125;/malicious_user_mitigations/&#123;name&#125;` | 悪意あるユーザー軽減の取得。 |
| DELETE | `/api/config/namespaces/&#123;namespace&#125;/malicious_user_mitigations/&#123;name&#125;` | 悪意あるユーザー軽減の削除。 |
