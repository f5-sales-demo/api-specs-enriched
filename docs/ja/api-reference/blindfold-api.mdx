ポリシーベースのアクセス制御による暗号化キー管理。監査ログおよびセキュアなデータ保護。

- **カテゴリ**: セキュリティ
- **複雑度**: 中程度
- **パス数**: 27 | **スキーマ数**: 163
- **ティア**: アドバンスト
- **関連ドメイン**: `client_side_defense`, `certificates`

## ユースケース

- 暗号化のためのシークレットポリシーの設定
- 機密データ暗号化の管理
- データ保護ポリシーの適用

## 主要リソース

- **blindfold_secret**: Blindfold 暗号化を使用した暗号化済みシークレット
- **secret_policy**: シークレット管理ポリシーの設定
- **policy_document**: アクセス制御定義のためのポリシードキュメント
