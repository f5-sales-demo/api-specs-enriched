自動有効期限付きのサイト登録認証情報。タクソノミーキーは許可された分類を定義し、自動導出タグは動的に適用されます。

- **カテゴリ**: プラットフォーム
- **複雑度**: シンプル
- **パス数**: 13 | **スキーマ数**: 50
- **ティア**: Standard
- **関連ドメイン**: `system`, `admin`

## ユースケース

- ユーザーアカウントとトークンの管理
- ユーザー識別情報の設定
- ユーザー設定と環境設定の管理
- 暗黙的ラベルおよび既知ラベルの設定

## 主要リソース

- **user**: プラットフォームアクセス用のユーザーアカウント
- **user_role**: 権限管理用のユーザーロール
- **namespace_role**: きめ細かな権限制御のための名前空間スコープのロール
