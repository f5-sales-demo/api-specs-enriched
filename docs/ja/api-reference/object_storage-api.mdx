モバイルアプリインテグレーター向けのバージョン管理されたライブラリ配布。事前署名済み URL により、iOS および Android 向けの OS 固有ビルドの安全なダウンロードが可能です。

- **カテゴリ**: プラットフォーム
- **複雑度**: シンプル
- **パス数**: 9 | **スキーマ数**: 17
- **ティア**: Advanced
- **関連ドメイン**: `marketplace`

## ユースケース

- オブジェクトストレージサービスの管理
- 保存オブジェクトおよびバケットの設定
- ストレージポリシーの管理

## 主要リソース

- **object_store**: Blob ストレージ管理用のオブジェクトストア
- **bucket**: オブジェクトストレージ用のストレージバケット
