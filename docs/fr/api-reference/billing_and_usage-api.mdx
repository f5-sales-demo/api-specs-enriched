Transitions de plan, facturation et consommation des ressources. Limites de quota au niveau de l'espace de noms et suivi de l'utilisation.

- **Catégorie** : Plateforme
- **Complexité** : modérée
- **Chemins** : 25 | **Schémas** : 101
- **Niveau** : Standard
- **Domaines associés** : `system`, `users`

## Cas d'utilisation

- Gérer les abonnements et les transitions de facturation
- Configurer les méthodes de paiement et les factures
- Suivre l'utilisation des quotas de ressources entre les espaces de noms
- Surveiller les limites d'utilisation et la capacité

## Ressources principales

- **subscription** : Abonnement pour les droits de service
- **quota** : Quota de ressources pour les limites d'utilisation
- **usage_report** : Rapport d'utilisation pour le suivi de la consommation
