Versionierte Bibliotheksverteilung für Integratoren mobiler Apps. Vorsignierte URLs ermöglichen sichere Downloads mit betriebssystemspezifischen Builds für iOS und Android.

- **Kategorie**: Plattform
- **Komplexität**: einfach
- **Pfade**: 9 | **Schemata**: 17
- **Stufe**: Erweitert
- **Verwandte Domänen**: `marketplace`

## Anwendungsfälle

- Objektspeicherdienste verwalten
- Gespeicherte Objekte und Buckets konfigurieren
- Speicherrichtlinien verwalten

## Primäre Ressourcen

- **object_store**: Objektspeicher für die Verwaltung von Blob-Storage
- **bucket**: Speicher-Bucket für Objektspeicher
