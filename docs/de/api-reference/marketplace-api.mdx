Drittanbieter-GRE- und IPSec-Tunnel-Bereitstellung mit DPD-Timern. Gemeinsame Ressourcenzuweisung über Namespaces hinweg mit Kachel-Platzierungssteuerungen.

- **Kategorie**: Plattform
- **Komplexität**: moderat
- **Pfade**: 36 | **Schemas**: 183
- **Stufe**: Erweitert
- **Verwandte Domänen**: `bigip`, `admin`

## Anwendungsfälle

- Auf Drittanbieter-Integrationen und Add-ons zugreifen
- Marktplatz-Erweiterungen verwalten
- Terraform- und externe Integrationen konfigurieren
- TPM-Richtlinien verwalten

## Primäre Ressourcen

- **marketplace_item**: Marktplatz-Element für den Dienstkatalog
- **subscription**: Abonnement für Dienst-Berechtigungen
