Globale Verteilung mit Cache-Regeln und Löschoperationen. Leistungsüberwachung und Analysen.

- **Kategorie**: Netzwerk
- **Komplexität**: erweitert
- **Pfade**: 29 | **Schemata**: 592
- **Stufe**: Erweitert
- **Verwandte Domänen**: `virtual`

## Anwendungsfälle

- CDN-Lastverteilung konfigurieren
- Dienste zur Inhaltsbereitstellung verwalten
- Caching-Richtlinien konfigurieren
- Datenbereitstellung und -verteilung verwalten

## Primäre Ressourcen

- **cdn_loadbalancer**: Lastverteiler für Netzwerke zur Inhaltsbereitstellung für Edge-Caching
- **cdn_origin_pool**: Ursprungsserver-Pool für CDN-Inhaltsquellen
