การจัดการ Identity ด้วยการผสานรวมผู้ให้บริการ, นโยบายการเข้าถึง, และการควบคุมวงจรชีวิตข้อมูลรับรองตัวตน

- **หมวดหมู่**: แพลตฟอร์ม
- **ความซับซ้อน**: ง่าย
- **เส้นทาง**: 14 | **สคีมา**: 38
- **ระดับ**: Standard
- **โดเมนที่เกี่ยวข้อง**: `system`, `users`

## กรณีการใช้งาน

- กำหนดค่ากลไกการตรวจสอบสิทธิ์
- จัดการผู้ให้บริการ OIDC และ OAuth
- กำหนดค่าการจัดเตรียมผู้ใช้ด้วย SCIM
- จัดการข้อมูลรับรอง API และการเข้าถึง
- กำหนดค่านโยบายการสมัครบัญชี

## ทรัพยากรหลัก

- **authentication_policy**: นโยบายการตรวจสอบสิทธิ์สำหรับการเข้าถึงของผู้ใช้และ API
- **token**: โทเค็น API สำหรับการเข้าถึงแบบโปรแกรม
- **api_credential**: ข้อมูลรับรอง API สำหรับการตรวจสอบสิทธิ์บริการ
