إدارة الهوية مع تكامل الموفر وسياسات الوصول والتحكم في دورة حياة بيانات الاعتماد.

- **الفئة**: المنصة
- **التعقيد**: بسيط
- **المسارات**: 14 | **المخططات**: 38
- **المستوى**: قياسي
- **النطاقات ذات الصلة**: `system`، `users`

## حالات الاستخدام

- تكوين آليات المصادقة
- إدارة موفري OIDC وOAuth
- تكوين توفير مستخدمي SCIM
- إدارة بيانات اعتماد API والوصول
- تكوين سياسات تسجيل الحساب

## الموارد الأساسية

- **authentication_policy**: سياسة المصادقة لوصول المستخدم وAPI
- **token**: رمز API للوصول البرمجي
- **api_credential**: بيانات اعتماد API لمصادقة الخدمة
