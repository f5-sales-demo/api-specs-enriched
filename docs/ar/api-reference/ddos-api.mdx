قوائم الرفض ومجموعات قواعد جدار الحماية والضمانات القائمة على الأنفاق. تحديد معدل الطلبات وتحليل الأنماط لأمان محيط الشبكة.

- **الفئة**: الأمان
- **التعقيد**: متقدم
- **المسارات**: 60 | **المخططات**: 246
- **المستوى**: متقدم
- **النطاقات ذات الصلة**: `network_security`, `virtual`

## حالات الاستخدام

- تهيئة سياسات حماية DDoS
- مراقبة وتحليل تهديدات DDoS
- تهيئة حماية البنية التحتية

## الموارد الأساسية

- **ddos_protection**: تهيئة حماية DDoS لتنقية حركة المرور
- **ddos_mitigation_rule**: قاعدة تخفيف DDoS للاستجابة للهجمات
