بيانات اعتماد تسجيل الموقع مع انتهاء صلاحية تلقائي. تحدد مفاتيح التصنيف التصنيفات المسموح بها بينما تُطبَّق العلامات المشتقة تلقائياً.

- **الفئة**: المنصة
- **التعقيد**: بسيط
- **المسارات**: 13 | **المخططات**: 50
- **المستوى**: قياسي
- **النطاقات ذات الصلة**: `system`، `admin`

## حالات الاستخدام

- إدارة حسابات المستخدمين والرموز
- تهيئة تعريف المستخدم
- إدارة إعدادات المستخدم وتفضيلاته
- تهيئة التسميات الضمنية والمعروفة

## الموارد الأساسية

- **user**: حساب مستخدم للوصول إلى المنصة
- **user_role**: دور المستخدم لإدارة الصلاحيات
- **namespace_role**: دور محدد نطاقه بـ namespace لصلاحيات دقيقة
