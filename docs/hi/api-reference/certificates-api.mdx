प्रमाणपत्र चेन और विश्वसनीय CA बंडल। PKI संचालन के लिए निरसन सूची प्रबंधन और मैनिफेस्ट कॉन्फ़िगरेशन।

- **श्रेणी**: सुरक्षा
- **जटिलता**: मध्यम
- **पथ**: 16 | **स्कीमा**: 74
- **स्तर**: मानक
- **संबंधित डोमेन**: `blindfold`, `system`

## उपयोग के मामले

- SSL/TLS प्रमाणपत्र प्रबंधित करें
- विश्वसनीय CA कॉन्फ़िगर करें
- प्रमाणपत्र निरसन सूचियाँ (CRL) प्रबंधित करें
- प्रमाणपत्र मैनिफेस्ट कॉन्फ़िगर करें

## प्राथमिक संसाधन

- **certificate**: सुरक्षित HTTPS कनेक्शन के लिए TLS प्रमाणपत्र
- **ca_certificate**: ट्रस्ट चेन के लिए प्रमाणपत्र प्राधिकरण प्रमाणपत्र
- **certificate_chain**: पूर्ण ट्रस्ट सत्यापन के लिए प्रमाणपत्र चेन
